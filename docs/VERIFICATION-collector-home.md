# 安卓采集与同步首页验收记录

日期：2026-09-21

## 已实现

- 本机状态来源为 SharedPreferences / Keystore、原 SQLite meta/events/coverage 与三个原有唯一 WorkManager 任务，读取不等待看板 API。
- 采集启用与使用情况权限分别展示，不以开关状态保证后台运行。
- 同步状态区分暂停、未同步、等待执行、等待网络、同步中、失败、成功。上次成功时间只在服务端确认合法 ACK 后写入；有积压或任务排队时不显示整体同步成功。
- 手动提交使用 KEEP 去重并禁用按钮，失败后重试复用原唯一上传任务重新入队；自动采集与周期频率不变。
- 首页、详情、设置导航和系统返回；首次配置步骤；跟随系统浅深色；20dp 页面边距，12–16dp 间隔，正文16sp／辅助14sp，长内容滚动。
- 今日摘要及详情共享不携带上传密钥的看板 GET，前台每分钟刷新；刷新失败保留已有数据，ViewModel 保留旋转后的数据；切换服务器清除旧服务端缓存。
- 不变更服务端、协议、包名、密钥存储、数据库版本和表结构。sync_error 仅为原 meta 表中的附加状态键，不做数据库迁移。
- 旧配置、队列保留；保存空白密钥仍保留旧密钥。更换服务器沿用原重新标记待上传逻辑，并清除旧服务器成功时间。

## 待实机验收

本次 adb devices -l 无连接设备；本机没有 Android 模拟器可执行文件。以下项目未进行设备测试，代码检查与状态单元测试不能代替这些验收。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 首次安装 | 在测试设备全新安装，保存合法格式 HTTPS 地址和密钥，再授权、启用 | 按三个步骤引导；未完成前不假称成功；密钥输入只在设置 |
| 已有配置升级 | 同签名覆盖安装，禁止卸载或清数据 | 直接首页；原地址、密钥、启用状态、间隔、待上传记录保留 |
| 暂停与恢复 | 设置中暂停，回首页恢复 | 暂停取消原任务；恢复复用原任务与频率，保留队列 |
| 权限撤销 | 系统撤销使用情况权限，返回 App | 首页刷新权限状态并提供去授权，不将启用等同运行正常 |
| 离线积压 | 断网后采集，打开 App，再恢复网络 | 本机时间及队列可见；等待网络；恢复后上传 |
| 错误密钥 | 在测试服务器用格式合法但错误密钥同步 | 显示密钥错误和连接设置入口；修正并保存后可重试 |
| 服务端故障 | 测试服务返回 5xx 或不可达 | 本机状态仍可见；队列保留；显示失败、网络操作与重试 |
| 手动重试 | 失败后恢复测试服务并点击重试 | 原唯一上传任务重新入队，成功仅在服务端 ACK 后 |
| 重复点击 | 连续快速点击同步／首次同步 | 按钮禁用且唯一任务 KEEP 去重，不累计手动任务 |
| 摘要断网 | 成功读摘要与详情后断网再刷新 | 保留旧值，提示刷新失败和原更新时间，不用零替代缺失 |
| 无记录／跨日 | 无 snapshot 或不完整零值；隔日离线重开 | 缺失显示破折号，昨天缓存不当作今日摘要 |
| 详情 | 切换日期、7/30天、亮屏/解锁趋势及事件筛选 | 日期和数据对应，空事件提示最近100条范围 |
| 返回导航 | 首页→详情／设置→系统返回 | 回首页，无底部导航；首页系统返回退出 |
| 显示适配 | 320dp小屏，系统字体最大，浅色/深色，旋转屏幕 | 无关键文字裁切，内容可滚动，控件可操作，旧摘要保留 |
| 网页入口 | 首页打开完整网页 | 浏览器打开保存的服务器地址，不附带上传密钥 |

版本保持工作区 0.5.2 / versionCode 8；本次为独立命名的 Debug 构建，不代表已在设备或生产环境验收。
